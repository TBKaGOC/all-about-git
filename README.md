# Git
Git — самая популярная система контроля версий(VCS). Git позволяет сохранять разные версии одного и того же проекта и откатывать изменения к необходимому сохранению. Git является консольным приложением и использует командную строку.

Хеш — уникальный индентификатор для коммита.

Лог — перечесление краткой информации о каждом коммите.

HEAD — файл с ссылкой на последний коммит.

Всё нижеприведённое верно для Windows.

## Особые обозначения
1. ~ — обозначение домашней директории.
2. .. — обозначение родительской директории.
3. /(одиночная) — обозначение корневой директории.

## Команды
Любая команда начинается с символа $, он появляется сам.
1. pwd — позволяет увидеть нынешнее местоположение.
2. cd [путь] — перемещает в указанную директорию.
3. ls — показывает содержание нынешнего местоположения. a) ls -a — показывает скрытое содержимое нынешней директории.
4. touch [имя_файла] ([имя_файла2] и т.д.) — создаёт файл в нынешней директории.
5. mkdir [имя_директории] — создаёт новую директорию в нынешней директории. a) mkdir -p [имя_директории/имя_поддиректории/...] — создаёт структуру директорий.
6. cp [что_копируем] [куда_копируем] ([что_копируем2] [куда_копируем2] и т.д.) — копирует файлы.
7. cat [имя_файла] — читает содержание указанного файла.
8. rm [имя_файла] — удаляет файл. a) rm -r [имя_директории] — безвозртано удяляет директорию со всем содержимым.
9. rmdir [имя_директории] — удаляет директорию(не влияет на не пустые директории).
10. git version — проверяет версию Git-а.
11. git config --global — позволяет менять глобальные настройки Git-а.
12. git init — инициализирует локальный репозиторий в нынешней директории.
13. rm -rf .git — позволяет уничтожить локальный репозиторий в нынешней директории.
14. git status — показывает нынешнее состояние репозитория.
15. git add [имя_файла] (--all, чтобы отслеживать всё) — позволяет отслеживать файл в репозитории.
16. git commit -m 'сообщение' — создаёт коммит.
17. git log — показывает историю коммитов.
18. git remote add [имя_удалённого_репозитория] [ключ_для_связи] — привязывает удалённый репозиторий к локальному.
19. git remote -v — показывает связаны ли репозитории.
20. git push (-u [имя_удалённого_репозитория] [имя_ветки] при первой отправки) — отправляет изменения на удалённый репозиторий.
21. git clone [ключ_для_связи] — клонирует удалённый репозиторй в локальный.
22. javac -encoding UTF-8 [имя java-файла] — компилируте исходный код в байт код.
23. java -Dfile.encoding=UTF-8 [имя java-файла] — запускает скомпилированый код.
24. git log (--oneline) — выводит лог репозитория.

## Полезные инструменты
1. && — позволяет воспользоваться несколькими командами в одной строке.
2. [Tab] — автодополнение.
3. Буфер обмена — возвращает к предыдущей(↑) или последующей(↓) команде.
